Scaffold EF core từ database để lấy entity với db context:

Scaffold-DbContext "server=(local); database=database; uid=sa; pwd=12345; TrustServerCertificate=True;" Microsoft.EntityFrameworkCore.SqlServer -OutputDir Models -Force


Tạo folder Configuration ở infrastructure, xong tạo class DependencyInjection.cs rồi lấy cái này vào:

public static IServiceCollection AdđDependencyInjection(this IServiceCollection services, IConfiguration configuration)
{
	var connectionString = configuration.GetConnectionString("DefaultConnection");

	services.AddDbContext<UserOnlyContext>(options =>
		options.UseSqlServer(connectionString)
	);

	return services;
}
